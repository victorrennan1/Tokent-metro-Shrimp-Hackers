# Tokentômetro Collector

Requer Node.js 20+. Execute com `pnpm --filter tokentometro dev -- <comando>` durante o desenvolvimento.

O adaptador `ccusage@20.0.36` é encapsulado em `src/core.ts`. O coletor lê somente metadados e não envia prompts, respostas, código, credenciais ou caminhos absolutos.
